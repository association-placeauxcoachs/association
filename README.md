# Association PlaceAuxCoachs

L'association PlaceAuxCoachs porte [PlaceAuxCoachs](https://placeauxcoachs.fr), une application gratuite de création et de partage d'entraînements de handball, développée bénévolement pour les entraîneurs.

L'association est **en cours de création**. Ce dépôt publiera ses documents officiels à mesure qu'ils sont adoptés.

## Ce qui est publié ici

| Dossier | Contenu |
|---|---|
| [`statuts/`](statuts/) | Statuts et règlement intérieur en vigueur, avec leur historique de modification |
| [`assemblees/`](assemblees/) | Comptes rendus approuvés des assemblées générales |
| [`finances/`](finances/) | Budgets votés et rapports financiers |
| [`decisions/`](decisions/) | Décisions du bureau |

Les évolutions de l'application elles-mêmes se proposent dans le dépôt [`produit`](https://github.com/association-placeauxcoachs/produit).

## Règles de publication

- **Seuls des documents adoptés** sont publiés : aucun brouillon, aucune négociation en cours.
- **Un compte rendu ne cite nommément que les membres du bureau** et les personnes ayant donné leur accord.
- **Aucune liste d'adhérents ni coordonnée personnelle.**
